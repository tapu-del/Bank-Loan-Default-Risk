# Bank Loan Default Risk Dashboard

## Project Overview
Built a professional, dark-themed Power BI dashboard to analyze bank loan default risks across 148,000+ records. 

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed total loans, loan amounts, and average credit scores.
- Created 4 KPI cards with custom styling.
- Built a Donut chart to show the Default vs Safe loan distribution.
- Used Binning to group Credit Scores and visualize risk by score range.
- Added a Year-over-Year trend chart for loan amounts.
- Added interactive slicers for dynamic filtering.

## Key Insights
- **Total Records:** 148.67K
- **Total Loan Amount:** 49.23 Billion
- **Default Rate:** 75.36%
- **Credit Risk:** The 600-700 credit score range holds the highest volume of loans.
